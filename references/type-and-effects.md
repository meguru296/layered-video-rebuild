# 文字与效果

## 文字来源与字体

先核对实际文字、字形语言、大小写、标点、换行和出现区间。对歌词、引文或署名，优先用原片及作者发布的文字交叉核对；需要在线查证时使用当前可访问的原发布来源。不要在 skill 或交接材料中复制与复现无关的整篇歌词。

字体统一是视觉层级一致，不一定是所有地方只有一种字体。分别匹配小字幕、大字、标题和署名；同一角色的文本保持家族、粗细、字距与位置逻辑。中英日混排检查缺字、字体回退、行高和视觉重量；片尾新加的一行应融入原有署名层级。

从较清晰、较稳定的帧测字，不从粒子化或被衣纹穿过的帧估字体。字号、字宽、字重、缩放与描边可互相补偿，不能只凭模板相关性最高就确定字体。精确字体未知时写明匹配近似。

使用排版引擎的实际 shaping/advance/kerning 和字形边界，不能把 `字数 × 字号` 当作通用宽度。逐字拆图时为笔画外伸、标点和重音留够单元空间；保留实际 advance、基线和局部锚点，避免切掉细笔画或重复绘制邻字。

在目标字号或适度超采样后生成透明字形。放大的低分辨率字幕、边缘提取出的字和画面里抠出的模糊字，都不能由高码率编码恢复清晰。

## 合成模型：字色不一定真的变化

采用一致颜色空间约定，先观察字形覆盖前后的像素关系。普通黑字 alpha-over 可写作：

```text
C = (1 - α) * B + α * 0
```

它只能让背景变暗，不能使同一字形区域亮于干净背景。若同一类文字既有压暗又有提亮，需要考虑反相、差值、分区遮罩、其他混合方式或底图本身发生变化；不能仅用黑字透明度解释全部现象。

差值候选 `C = abs(B - F)` 与含 alpha 的实际输出，需结合软件的颜色空间、预乘和混合规则测试。不是看到黑白翻转就能断定原作者使用某个具体模式。给出可验证推断，不声称恢复唯一的内部工程。

有后续无字帧时，先把无字背景配准到有字帧，再看字形位置的明暗变化；没有干净底图时用多个邻帧和相同字的稳定笔画建立证据，避免把人物变化当字色变化。

可用的独立重建方式包括：

- 固定字色配透明度曲线。
- 干净字形配差值或反相合成。
- 黑字母版配新的前景区域遮罩，在需要的区域进行反相。

选择能重现实际效果且时间上稳定的最简单模型。不依据每帧噪声给同一个字随机换颜色。保持字形 alpha 不变，把合成遮罩与字形边缘分开；用户要求无描边时，不膨胀 alpha，不加暗边、亮边、投影或底框。跨明暗背景出现的色差不是自动增加描边的理由。

## 锚点与逐字动效

每个字保存：文字内容、字形文件、真实尺寸、基线/锚点、最终位置、全局区间及变换/透明度关键帧。进入与离开的状态分开，落定后锁住位置，不再随背景纹理重新跟踪。

居中使用实际可见字形或排版边界，并明确是相对画面、栏位还是角色位置居中。只看文本框或字符数量，容易让整行视觉偏左/偏右。

观察连续帧判断入场方式：部件分离、缩放、位移、旋转、遮罩显现、透明度或它们的组合。可分成进入、减速落定、保持和退场；用少量关键帧拟合速度变化，不把首尾帧之间简单匀速插值当作所有效果。检查中心、旋转中心和基线，而不只看首尾相似。

常见错误是用短窗口拟合多项式，再继续外推到保持阶段，导致文字抖动、突然消失或飞出画面。到达落定点就切换为明确的稳定状态。字的退场时点也不能用“最亮像素消失”判定，灰化的笔画仍可能可见。

## 大字与粒子消散

区分整体透明度、模糊、噪声侵蚀、碎块位移和真正的粒子运动。普通淡出不能代替粒子化退场。

若只需近似，可用每个字固定种子的噪声/粒子场，随时间单调推进阈值、密度及必要的位移；不要每帧重新随机，造成整块文字闪烁。先匹配可读阶段、停留时长、灰化和尾部残留，再调整颗粒细节。若参考存在粒子扩散运动，单纯噪声侵蚀仍是近似，需要说明或增加对应运动。

对于拆部件的大字，分别拟合部件运动，保留它们的层级关系。只调整整字的缩放和透明度不能解释部件以不同方向或速度进入的效果。

## 光场、虚焦和闪光

空间光场、镜头色散、几何图案和纯白闪光是不同层。按参考核对光带宽窄、倾斜、亮度分布、色彩饱和度、遮挡和衰退，避免把柔和折射光重建为规则硬条。

只有真正的全画面退焦才作用于文字和背景一起。由人物拟合或纹理估算得到的模糊参数，不应自动模糊正常字幕。物体局部虚焦、光晕和镜头退焦分别处理。

切点附近同时看退焦、曝光、闪白覆盖和内容换图时刻。若用白光遮住换图，旧内容应保持到覆盖足够强，新内容在遮蔽之后显现；不能只在切点补一张白帧掩盖两侧缺失的运动。原片有意的硬切无需额外叠化。
